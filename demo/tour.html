NewsDeck

An AI news triage board: ten RSS feeds → normalized, deduplicated, auto-tagged cards you filter, star and clear.
Every part of the build runs on Kiro features — here's the tour.

React 19 + TS client Express fetch server + snapshot cache fast-check property tests zero-dep MCP server
Lesson 1

Spec-driven development

.kiro/specs/news-triage/{requirements.md, design.md, tasks.md}
# requirements.md — EARS notation, 7 requirements, glossary
WHEN a Source request fails or times out
THE SYSTEM SHALL record a SourceError and continue with remaining feeds

WHEN items are listed
THE SYSTEM SHALL order them by publishedAt descending,
breaking ties on id for a stable total order
requirements → design → tasks 15 correctness properties feed the PBT suite
Lesson 2

Steering documents

.kiro/steering/{typescript-style.md, project-context.md}
# typescript-style.md
- shared/ is pure: no DOM, no Node APIs, no Date.now() — pass
  timestamps in. Keeps every function property-testable.
- No any — use unknown and narrow. Side effects live in
  server/ and src/ only.
always-on conventions architecture map + invariants
